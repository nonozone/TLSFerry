# TLSFerry 产品说明

## 一句话介绍

TLSFerry 是一套面向网站、CDN 和对象存储场景的 TLS 证书自动化管理产品，帮助用户完成证书申请、部署、续期和状态管理，降低因证书过期或操作失误导致 HTTPS 服务中断的风险。

## TLSFerry 主要做什么

当一个团队同时维护多个域名、CDN 或云平台时，TLS 证书通常分散在不同控制台中。每次证书更新，都可能涉及域名验证、证书申请、私钥保管、上传证书、绑定域名和确认生效等多个步骤。

TLSFerry 把这些步骤连接成一条可重复、可自动执行的流程：

1. 发现或录入需要管理的云端域名；
2. 通过 ACME DNS-01 自动申请可信证书，并支持通配符证书；
3. 将证书部署到对应的 CDN 或对象存储服务；
4. 在证书临近到期前自动续期并重新部署；
5. 查看证书状态、到期时间和最近一次执行结果。

用户不再需要为每张证书反复登录多个云平台，也不必依靠日历、表格或人工记忆跟踪到期时间。

## 解决的主要痛点

### 1. 容易忘记续期，证书过期会直接影响业务

证书过期会导致浏览器安全警告、接口调用失败，严重时会让网站或 CDN 服务不可用。TLSFerry 会按照设定的时间检查证书，在到期前自动完成续期和重新部署。

### 2. 申请、上传和绑定流程重复且容易出错

传统流程需要在证书机构、DNS 服务商和云平台之间来回操作。域名越多、云平台越多，重复劳动和误操作风险越高。TLSFerry 将签发与部署串联起来，让同一张证书可以按配置交付到一个或多个目标。

### 3. DNS 验证操作繁琐

DNS-01 验证通常要求创建和清理临时 TXT 记录。CE 可以直接调用用户选择的 DNS 服务商完成验证；Cloud 则通过一次 CNAME 委托管理后续验证，正常续期时无需反复修改业务 DNS。

### 4. 长期云密钥和证书私钥存在安全压力

CE 将云凭据保存在用户自己的操作系统凭据管理器或受控运行环境中，主配置文件不保存明文密钥。Cloud 连接腾讯云时使用最小权限角色和短期授权，不要求客户把长期 SecretId、SecretKey 或证书私钥保存到控制台数据库中。

### 5. 多域名、多平台缺少统一管理方式

不同云平台的证书入口、状态和更新方式并不一致。TLSFerry 用统一的流程管理证书生命周期，减少团队为不同平台分别维护脚本和操作手册的成本。

## CE 版与 Cloud 版

TLSFerry 提供两种使用方式。两者共享相同的证书自动化核心，区别主要在于由谁负责运行和维护。

| 版本 | TLSFerry CE | TLSFerry Cloud |
| --- | --- | --- |
| 产品形态 | 开源、自托管的命令行工具 | 托管式 Web 控制台与自动化服务 |
| 适合用户 | 希望完全控制运行环境和凭据的开发者、运维团队 | 希望减少部署、配置和日常维护工作的个人或小团队 |
| 运行维护 | 用户在自己的电脑、服务器、NAS 或 CI 中运行 | TLSFerry 负责控制面和任务编排的运行维护 |
| 凭据与私钥 | 凭据和证书私钥保留在用户控制的环境中 | 腾讯云采用最小权限角色和短期授权；证书私钥不进入控制台数据库 |
| 使用方式 | 通过配置文件、CLI 和系统定时任务管理 | 通过控制台连接云账户、选择域名并查看证书状态 |
| 当前云平台范围 | 腾讯云 CDN/COS、阿里云 CDN、七牛 CDN；DNS 支持 Cloudflare、DNSPod 和阿里云 DNS | 当前重点支持腾讯云 CDN |
| DNS 验证 | 使用用户自己的 DNS 凭据自动创建和清理临时记录 | 首次添加一条专属 CNAME，之后由服务完成验证记录管理 |

CE 不是功能被刻意限制的试用版。它保留完整的证书签发、续期和多云部署能力，适合需要自托管、可审计和高度可控环境的用户。

Cloud 提供的核心价值是“少维护”：用户完成一次云账户授权和 DNS 委托后，系统负责后续任务调度、证书签发、上传部署和自动续期，并在控制台集中展示域名与证书状态。

## 典型使用场景

- 网站或 API 使用 CDN，希望避免证书过期造成访问中断；
- 同一个团队维护多个域名，需要集中跟踪证书有效期；
- DNS 和 CDN 分属不同服务商，需要自动完成跨平台证书交付；
- 证书需要同时部署到多个云端目标，不想重复上传和绑定；
- 小团队没有专职运维，希望把证书续期变成长期自动运行的服务；
- 对凭据和私钥控制要求较高，希望使用自托管方案或最小权限的云授权方式。

## 产品价值

TLSFerry 将原本分散、重复且容易遗漏的证书维护工作，变成一条安全、明确、可持续运行的自动化流程。它既为技术团队提供可自托管的 CE 版，也为希望降低运维成本的用户提供 Cloud 版，让 HTTPS 证书从一项需要持续惦记的工作，变成可以交给系统完成的基础能力。

> 当前产品范围说明：TLSFerry CE 已实现多云证书自动化能力；TLSFerry Cloud 当前聚焦腾讯云 CDN 的域名发现、证书签发、部署与自动续期。其他云平台的 Cloud 托管能力应以正式发布信息为准。
